# WapProjectForPaintTrekDesktop

Bu proje, **Paint Trek** oyununun masaüstü (.NET 9.0 WindowsDX) sürümünü Microsoft Store için paketleyen **Windows App Packaging (WAP)** projesidir.

## Güvenlik ve yayınlama

Paket çıktıları (`bin`, `obj`, `AppPackages`, `BundleArtifacts`), imzalama sertifikaları
ve yerel Microsoft Store ilişkilendirme dosyası (`Package.StoreAssociation.xml`) Git'e dahil edilmez.
Microsoft Store'a yüklemek için kendi makinenizde Store association ve imzalama sertifikasını ayarlayın.
